*Search using inline mode*

To send a previously saved message, you should use the bot using the [inline mode](https://telegram.org/blog/inline-bots) provided by Telegram.


*Guest mode*

You can also write my username followed by an alias in any chat, even if I am not a member of it. I will answer with the first fav found by the alias.
To save a fav this way, mention me in a reply to the message with the keyword `save` (or `create`) and an alias: `save <alias>`.
Other commands work the same way: `delete <alias>` and `ref` (in a reply), `list`, `link <new> -> <existing>`, `remove link <name>` and `help`.
